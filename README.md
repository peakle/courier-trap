# courier-trap

Распознаёт 5-значный номер курьера на термокоробе (белая наклейка с тёмными цифрами)
и отправляет на бэкенд события визитов: `visit_confirmed` (курьер подтверждён) и
`visit_closed` (курьер уехал).

## Сборка (Ubuntu 24.04)

```bash
sudo apt install golang-go libopencv-dev tesseract-ocr libtesseract-dev libleptonica-dev
go build -o courier-trap .
```


## Macos

```bash
xcode-select --install          # clang для cgo, если ещё не стоит
brew install go opencv@4 tesseract pkg-config
pkg-config --modversion opencv4 # запомнить версию
```

Версия gocv жёстко привязана к версии OpenCV: в Ubuntu 24.04 это OpenCV 4.6 → gocv v0.31.0
(см. `replace` в go.mod). Для свежей OpenCV поднимайте gocv соответственно.

## Запуск

```bash
# проверка на фото
./courier-trap -image photo.jpg

# камера → бэкенд
./courier-trap -src "rtsp://user:pass@10.0.0.5/stream1" -camera-id rest-17 \
  -backend https://api.example.com/courier-events -token "$TOKEN" -roi 0,300,1920,780

# без -backend события печатаются в stdout; -v логирует каждое чтение
```

## Как работает

1. Кадры анализируются с частотой `-fps` (2). Распознавание запускается при движении
   или раз в `-idle` (5 с), чтобы видеть стоящих курьеров.
2. Детектор: эвристика (цепочка из 4–6 одинаковых по высоте тёмных блобов) или
   YOLO ONNX через `-model` (бокс уточняется эвристикой).
3. OCR: выравнивание наклона, масштаб к цифре 48 px, Оцу, Tesseract (только цифры, одна строка).
   Чтение проходит, только если совпадает с `-pattern` и уверенность ≥ `-min-conf`.
4. Визиты: голосование по позициям; чтение с ошибкой в одной цифре приклеивается к
   открытому визиту. Подтверждение — `-min-reads` чтений и согласие ≥ `-min-agree`.
   Закрытие — номер не виден `-close-after` (3 мин).
5. Отправка: асинхронная очередь, ретраи с бэкоффом до 1 мин на 5xx/429/сетевые ошибки,
   4xx не повторяются. `event_id` уникален — дедуплицируйте по нему на бэкенде.

## Событие

```json
{"event_id":"…","type":"visit_confirmed","visit_id":"…","camera_id":"rest-17",
 "courier_id":"47616","first_seen":"…","last_seen":"…","reads":5,
 "agreement":0.96,"ocr_conf":95.7,"crop_jpeg":"<base64, только в visit_confirmed>"}
```

## Ограничения

- Эвристика читает горизонтальные номера с наклоном до ~±10° и высотой цифры от ~15 px.
  Вертикальные наклейки на боках короба не читаются — нужен поворот кадра на 90° или YOLO.
- Цифры на вывесках в кадре дадут ложные «визиты» — ограничивайте зону через `-roi`.
- Два курьера с номерами, отличающимися одной цифрой, одновременно в кадре склеятся в один визит.
- Очередь отправки в памяти: при перезапуске недоставленные события теряются.
- YOLO-ветка собрана, но не проверялась на реальной модели.
